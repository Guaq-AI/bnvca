# B.N. Vaidya & Associates (BNVCA)

A premier Chartered Accountancy firm based in Mumbai, providing comprehensive financial, tax, and advisory services since 1987.

## Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Forms**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)
- **Form Handling**: [FormSubmit.co](https://formsubmit.co/)
- **Analytics**: [Vercel Analytics](https://vercel.com/analytics)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Structure

- `src/app`: Next.js App Router pages and layouts.
- `src/components`: Reusable UI components.
- `src/data`: Structured content objects derived from firm documentation.
- `public`: Static assets (images, logos).
